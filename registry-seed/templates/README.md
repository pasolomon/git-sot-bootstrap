# templates/

Canonical project templates live in
[`pasolomon/git-sot-bootstrap`](https://github.com/pasolomon/git-sot-bootstrap)
under `templates/` — that repo is their source of truth so the bootstrap and
its templates version together. This folder exists for registry-specific
templates only (e.g. migration record template below).

- `migration-record.md.template` — used for entries under `migrations/`
