## Bug found and fixed during testing

`validate_one`: junk-file count used `find | grep -v | wc -l`; with zero junk
files `grep -v` exits 1 and `pipefail` aborted the whole validate run. Replaced
with a single `find -not -path` (also fixing an operator-precedence issue in
the original `-o` chain). Also removed an invalid `-q` from `git lfs pull` in
`restore_one`.
